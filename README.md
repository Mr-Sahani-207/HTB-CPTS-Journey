# 🛡️ Hack The Box (CPTS) — Penetration Testing Journey

Welcome to my cybersecurity lab notebook! Here, I document my hands-on learning, enumeration methodologies, privilege escalation techniques, and custom scripts as I progress through the **Hack The Box Certified Penetration Testing Specialist (CPTS)** path.

## 🎯 Core Focus Areas
- **Network Enumeration:** Nmap, Service Fingerprinting, SMB/DNS/SNMP Enumeration
- **Web Application Security:** Directory Fuzzing, SQLi, XSS, File Upload Vulnerabilities
- **Privilege Escalation:** Linux (SUID, Cron Jobs, Sudoers) & Windows Escalation
- **Scripting & Automation:** Bash, Python, and PowerShell helper scripts

## 📂 Repository Structure
- `/Writeups` — Step-by-step walkthroughs of retired HTB machines and lab challenges
- `/Cheatsheets` — Quick-reference command playbooks for enumeration and exploitation
- `/Scripts` — Custom automation tools built during lab practice
